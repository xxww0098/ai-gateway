AI-GateWay · IP-as-logo

flat-first、略带新拟物的角色标。统一 squircle、奶油色硅胶质感、两点眼睛；十个角色对应网关、密钥、账本与流式中转，供挑选后替换现用双拱门。

01 · 品牌青绿

守门狐

从底边探出的狐狸。尖耳 + 两点眼，对应「聪明路由、守住闸口」。

02 · 现标拟人

拱门灵

身体就是一扇拱门，中间挖空成通道。现用 C 形门径的角色化。

03 · 密钥

钥匙猫

陶土红底、奶油猫脸，鼻口做成钥匙孔。对应 API Key agw-。

04 · 值守

哨兵鸮

林绿底、圆身耳簇。夜间哨兵，对应鉴权与配额看守。

05 · 流式

流式海豚

深蓝底、顺滑弧线。对应 SSE / 流式转发，体态即数据流。

06 · 账本

账本丸

紫底糯米团，头顶一枚结算币。对应 Hold / Settle / Release。

07 · 代理

门童机

芥黄底圆角机器人，胸口一扇小门。对应上游执行与门童式转发。

08 · 模型云

云端灵

石板蓝底、三团叠云。对应多模型汇入同一朵云。

09 · 凭证

密钥熊

近黑底圆耳熊，身侧挂一把金钥匙。对应凭证加密与守护。

10 · 品牌合体

闸口蜗牛

黑底奶油蜗牛，壳上就是现用青绿双拱门。旧标以 IP 壳的形式留下。
